Verbunden
Willkommen! Schicke eine Nachricht an den Bot.
Beispiel: "Hello", "How much is a t-shirt?", "I want to order 2 pants"

API-Endpunkte

Alle verfügbaren REST- und WebSocket-Endpunkte der RuleBot API. Basis-URL: http://localhost:8083

REST API

POST /api/chat
Nachricht an den Bot senden und Antwort erhalten.
Auth erforderlich
Request
{
  "message": "How much is a t-shirt?"
}
Response
{
  "response": "A T-shirt costs 25.00 Euro.",
  "intent": "ASK_PRICE"
}
GET /api/chat/history?limit=50
Chat-Verlauf aus der H2-Datenbank laden (neueste zuerst).
Auth erforderlich
Response
[
  {
    "id": 1,
    "text": "Hello",
    "sender": "user",
    "intent": "GREETING",
    "timestamp": "2026-11-19T14:00:00"
  },
  {
    "id": 2,
    "text": "Hello! How can I help you today?",
    "sender": "bot",
    "intent": "GREETING",
    "timestamp": "2026-11-19T14:00:01"
  }
]
DELETE /api/chat/history
Gesamten Chat-Verlauf aus der Datenbank löschen.
Auth erforderlich
Response
204 No Content

WebSocket

WS /ws
WebSocket-Endpunkt mit SockJS-Fallback. STOMP-Protokoll.
Auth erforderlich
SEND /app/chat/send
Nachricht an den Bot über WebSocket senden.
Payload
{
  "message": "I want to order 2 pants"
}
SUBSCRIBE /chat/response
Bot-Antworten in Echtzeit empfangen.
Response
{
  "response": "I have received your order for 2 Pants.",
  "intent": "ORDER"
}

Verfügbare Intents

Intent Beispiel Antwort
GREETING "Hello", "Hi" "Hello! How can I help you today?"
ASK_PRICE "How much is a t-shirt?" "A t-shirt costs 25.00 EUR."
ORDER "I want to order 2 pants" "I can help with that! 2 pants costs 55.00 EUR each. Total: 110.00 EUR."
CONFIRM "Yes", "OK" "Great! Your order has been confirmed. Thank you for shopping with us!"
CANCEL "No", "Cancel" "No problem, I've cancelled that. Is there anything else you need?"
GOODBYE "Bye", "Goodbye" "Goodbye! Have a great day!"
HELP "Help", "What can you do?" Liste der Befehle
SEARCH "Show me blue sneakers" "I found blue sneakers for 80.00 EUR. Would you like to order it?"
RETURN "I want to return" "You can return any item within 30 days of purchase."
SHIPPING "How long is shipping?" "Standard shipping takes 3-5 business days. Express (1-2 days) for 9.99 EUR."
